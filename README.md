# Factorial Calculator

A simple Python program that calculates the factorial of a given number.

## Description

This project contains a Python script, `factorial.py`, that calculates the factorial of a number using Python. It is a lightweight example suitable for learning basic Python programming concepts such as functions, input handling, and mathematical operations.

## Features

* Calculates the factorial of a given number
* Simple and easy-to-understand Python implementation
* Lightweight with no external dependencies
* Suitable for beginners learning Python

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository.git
```

Navigate to the project directory:

```bash
cd your-repository
```

No additional installation or package setup is required.

## Requirements

* Python 3.x
* No external Python packages are required

Check your Python version with:

```bash
python --version
```

## Usage

Run the program from the project directory:

```bash
python factorial.py
```

Follow the prompts provided by the program to enter a number.

## Example

For an input of:

```text
5
```

The program calculates:

```text
5! = 120
```

The factorial is calculated as:

```text
5 × 4 × 3 × 2 × 1 = 120
```
